# Organizing Your Sessions

Once agents do the delivery, you'll be running **several sessions at once**, across different repos, tasks, and sometimes machines. The hard part stops being the code and becomes keeping track of your agents.

- Which agent is still working?
- Which one is blocked, waiting on me?
- Where did I leave that session yesterday?

### herdr: where your coding agents live

[**herdr**](https://herdr.dev/) is an open-source (Apache 2.0) agent runtime that keeps your coding agents organized and running:

- **Always running:** sessions survive restarts, network drops, and a closed laptop lid. Your layout and agents resume where you left them.
- **Status at a glance:** every agent is shown as *working*, *blocked*, or *idle*, so you don't have to hunt through panes to find one that's stuck.
- **All your machines in one place:** connect your laptop, a desktop, or a remote server over SSH and manage every workspace from one view.
- **Works with the agents you already use:** Claude Code, Codex, Cursor, Copilot, opencode, and more.

Runs on Windows, macOS, and Linux.
