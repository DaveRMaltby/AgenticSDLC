# Code Is Cheap: Delivering Through Plans

Architecture at Tricentis works from a core assumption: with the arrival of agentic AI, **code is cheap**.

When writing code is no longer the bottleneck, the value of engineering shifts to deciding *what* to build and *how we'll know it's right*. We want the engineering organization to drive deliveries through **plans**: clear, reviewable descriptions of intent that agents can pick up and deliver.

This presentation offers suggestions and advice on how you and your team can move toward that way of working.
